# ProxyBridge Mod

自用修改版，基于官方 [ProxyBridge](https://github.com/InterceptSuite/ProxyBridge) 源码。  
包含 **v3.2.0** 和 **v4.0** 两个修改分支，本仓库持续维护。

---

## 📦 4.0 Mod 更新 (2026-08-08)

### 🚀 重大功能升级

1. **代理子进程支持**  
   规则内允许配置为代理此规则的程序下的所有子进程。  
   - 优先匹配子进程规则  
   - 如未设置子进程规则，则回落到本规则  

2. **代理回环保护**  
   实现子进程代理后，较大概率出现进程相互调用，特别是代理服务被代理到自身的情况。  
   - 触发时日志显示 `[LOOP GUARD]`

3. **允许代理链开关**  
   - 默认 **启用**“代理端点防回环”（即关闭允许代理链）  
   - 发现目标等于代理端点时自动直连  
   - 只有用户明确需要多级代理时才关闭防回环  

4. **日志与规则图标**  

   | 图标 | 含义 |
   |------|------|
   | ⚡ 闪电 | 子进程代理 |
   | ↕ 双箭头 | 父进程代理 |

5. **测试说明**  
   > ⚠️ 此为测试版本，稳定性尚不确定，欢迎反馈问题。

### 🛠 2026-07-10 更新

- 修复代理删除时规则引用错乱的问题（已提交官方 bug）  
- 移植原 3.2.0 的流量图标、流量统计、查看连接、只显示匹配规则日志等功能  
- 代理页面增加 **替换代理** 功能：将规则中所有 `proxy` 类型规则替换为选中的代理  
- 优化代理服务器设置界面，沿用 3.2.0 修改后的样式  
- 支持字体及字体大小设置  
- 增加代理流量统计

---

### 🐞 源码缺陷修复

修复连接映射清理和端口决策缓存未同步失效的问题：

1. `stale` 清理连接时同步 `port_clear(src_port)`（原只释放内存，未清除端口缓存）  
2. `remove_connection` 同步清空端口缓存  
3. TCP 映射保留时间从 **2 分钟** 提高至 **30 分钟**  
4. UDP 映射仍保留 **2 分钟**  
5. TCP/UDP 连接记录增加区分，避免误清理策略混用
